# wrapup

Close the session cleanly.

1. Run a checkpoint.
2. Check that nothing is left half written: no empty files, no unfinished functions.
3. List open questions for the owner, each with the decision it blocks.
4. Reply with a short table: done, open, needs the owner.

This is real money work: never write a number that is not backed by a function call or a source, and never place an order from a command.
