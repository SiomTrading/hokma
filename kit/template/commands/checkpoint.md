# checkpoint

Save progress so the work can resume later.

1. Write the current state of the task in one short note: goal, what is done, what is open, the files touched.
2. List every decision taken in this session and the reason for each.
3. List the numbers you computed with the function that produced each one and its source.
4. Save the note in the working folder under `checkpoints/` with the date in UTC in the file name.
5. Reply with the path of the note and one line saying what comes next.

This is real money work: never write a number that is not backed by a function call or a source, and never place an order from a command.
