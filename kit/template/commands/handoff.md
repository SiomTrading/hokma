# handoff

Hand the work to another agent.

1. State the task, the scope and the files the other agent may touch.
2. Attach the latest checkpoint and the hash of the data snapshot the work reads.
3. State the question the other agent must answer and the form of the answer.
4. Say what the other agent must not do: it does not place orders, does not read keys and does not edit files outside its scope.

This is real money work: never write a number that is not backed by a function call or a source, and never place an order from a command.
