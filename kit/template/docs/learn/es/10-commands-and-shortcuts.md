# Comandos y atajos

## Comandos de terminal

| Comando | Qué hace |
|---|---|
| `hokma start` | Abre tu fondo en el navegador |
| `hokma doctor` | Revisa que la instalación esté sana |
| `hokma update` | Instala la última versión |
| `hokma owner` | Cambia tu nombre y el nombre de tu fondo |
| `hokma ext list` | Muestra tus extensiones |
| `hokma db migrate` | Lleva la base de datos al último esquema |

## Comandos del chat

Escribe una barra en el cuadro de mensaje para verlos.

| Comando | Qué hace |
|---|---|
| `/modelo` | Cambia el modelo. Sin nombre abre el menú de modelos: `/modelo opus` |
| `/agente` | Manda los siguientes mensajes a un agente: `/agente vera` |
| `/proyecto` | Cambia el proyecto activo: `/proyecto principal` |

## Atajos de teclado

En macOS usa Cmd en lugar de Ctrl.

| Atajo | Qué hace |
|---|---|
| Ctrl N | Nueva conversación |
| Ctrl K | Buscar conversaciones |
| Ctrl y comilla invertida | Abrir o cerrar la terminal |
| Ctrl B | Menú izquierdo: expandido, íconos u oculto |
| Ctrl J | Panel derecho |
| Ctrl Shift F | Pantalla completa |
| Ctrl coma | Ajustes |
| Esc | Cierra un menú o una ventana |
