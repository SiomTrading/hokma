# Tareas programadas

Una tarea programada le pide a un agente que haga algo a la hora que eliges, por ejemplo un resumen diario de tus
proyectos.

## Crear una tarea

Abre **Tareas programadas** desde el menú más. Pulsa Nueva y completa:

- un nombre,
- el agente que hará el trabajo,
- la instrucción,
- el horario: diario, semanal, cada cierto número de minutos, o una sola vez,
- la zona horaria.

## Encenderla

Una tarea nueva empieza apagada. Al encenderla, Hokma muestra qué se va a ejecutar y te pide confirmar. Tu
confirmación queda guardada como una aprobación. Un agente no puede encender una tarea por su cuenta.

## Cuándo se ejecutan

Las tareas se ejecutan solo mientras Hokma está abierto. Si una tarea vencía con Hokma cerrado, queda marcada como
omitida al abrir Hokma de nuevo. No se ejecuta tarde.

## Resultados

Cada ejecución crea una tarea con el resumen, los tokens que usó y su resultado, y deja una línea en la bitácora.
