# Voz: notas de voz y transcripción

Hokma convierte tu voz en texto en tu propio computador. El audio nunca sale de tu equipo. Sirve para pedidos largos, para dictar tu diario y para corregir sin escribir.

## Preparar la voz (una sola vez)

1. En el chat, pulsa **Grabar nota de voz**.
2. Si Hokma ofrece descargar el modelo de voz, pulsa **Descargar**. Pesa unos cientos de MB.
3. Espera. Puedes seguir usando Hokma.

Debe verse: "Modelo listo. Pulsa el micrófono para grabar."

## Dictar un mensaje

1. Pulsa **Grabar nota de voz** y habla.
2. Pulsa **Detener y transcribir**.
3. Revisa el texto y envíalo.

Para descartar una grabación, pulsa **Cancelar grabación**. Una transcripción es texto: la puedes resumir, ordenar y pedirle al agente que la guarde en un archivo `.md`.

## Si algo falla

- **"El navegador no tiene permiso para usar el micrófono".** Permite el micrófono y vuelve a intentar.
- **"No se encontró un micrófono".** Conecta uno y reintenta.
- **"No se escuchó voz".** Habla más cerca del micrófono y graba de nuevo.
- **No se pudo descargar el modelo.** Revisa tu conexión y pulsa **Reintentar**.
- **"La voz no está disponible en este equipo".** Manda tu `engine.log`: mira "Solución de problemas".
