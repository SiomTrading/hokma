# Terminal

Hokma includes a real terminal inside the app. It opens in your working folder with your system shell.

## Open it

Press Ctrl and the backtick key, or use the Terminal button in the top bar. Press the plus button of the terminal
for a new one: each terminal has its own tab.

## What it is for

- Run Hokma commands such as `hokma doctor` or `hokma update`.
- Run `claude` inside your fund folder. It uses the same isolated configuration as the chat.
- Run any script the agents wrote in a project.

## Good to know

- Closing a terminal tab ends its process.
- The terminal is yours: what you type runs with your own permissions. The agents cannot type in it.
- It follows the size of the panel.
