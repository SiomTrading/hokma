# Agents

Your fund works with a team of agents. The orchestrator, Hokma, receives every message and sends the work to the
right specialist.

## See your agents

Open Settings and choose **Agents**. The orchestrator is on top and the rest are listed below it. Each one shows
what it does, whether it is active and which model it uses.

## Change the model of an agent

Press the model pill of the agent. It cycles Haiku, Sonnet and Opus. Hokma saves the choice and updates the agent
file in your working folder.

## Turn an agent on or off

Use the switch of the agent. An agent that is off cannot be chosen in the chat and does not take tasks.

## Create your own agent

Press "Create my first agent" and fill in a name, a description, a model and the instructions. Hokma writes the
agent file in your working folder, and you can talk to it with `/agente`.

## Talk to a specific agent

Type `/agente` and the agent name in the chat. The next messages go to that agent, and the header of the
conversation shows it.
