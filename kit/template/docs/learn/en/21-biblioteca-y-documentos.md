# Library and your own documents

Your agent can search your documents before it answers and tell you which file and section each fact came from. There are two places: a project's documents and the **Library**, which serves all your conversations.

## Add a document to the Library

1. In the menu, open **Library**.
2. Add your first document with **Add files** or drag it onto the screen.
3. Wait for the state to change from **Indexing** to **Ready**.

You should see: the document with its number of passages. It accepts PDF, Word, Excel, CSV, PowerPoint, Markdown, text, HTML and images, up to 50 MB per file. It is stored on your computer.

## Organize

1. Press **New folder**, type the name and press **Create**.
2. Move a document into a folder.
3. To rename or remove a folder, use its options menu. Removing a folder cannot be undone.

## Ask your documents

Ask in the chat in a concrete way: "According to my strategy, what is the maximum risk per trade? Tell me which file you got it from." A good answer cites its source or says it does not know. If it makes something up, ask it to quote the passage.

## If something fails

- **"Getting search ready..." does not finish.** Check your Internet connection. Hokma keeps trying. Press **Try again**.
- **"This document is already in the Library".** You do not need to upload it again.
- **The state says Failed.** Remove the document and upload it again.
