# Scheduled tasks

A scheduled task asks an agent to do something at a time you choose, for example a daily summary of your projects.

## Create a task

Open **Scheduled tasks** from the plus menu. Press New and fill in:

- a name,
- the agent that will do the work,
- the instruction,
- the schedule: daily, weekly, every so many minutes, or once,
- the time zone.

## Turn it on

A new task starts off. When you turn it on Hokma shows what will run and asks you to confirm. Your confirmation is
saved as an approval. An agent cannot turn a task on by itself.

## When tasks run

Tasks run only while Hokma is open. If a task was due while Hokma was closed, it is marked as skipped when you open
Hokma again. It does not run late.

## Results

Each run creates a task with the summary, the tokens it used and its result, and leaves a line in the journal.
