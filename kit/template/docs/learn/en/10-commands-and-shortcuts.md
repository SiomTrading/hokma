# Commands and shortcuts

## Terminal commands

| Command | What it does |
|---|---|
| `hokma start` | Opens your fund in the browser |
| `hokma doctor` | Checks that the installation is healthy |
| `hokma update` | Installs the latest version |
| `hokma owner` | Changes your name and your fund name |
| `hokma ext list` | Shows your extensions |
| `hokma db migrate` | Brings the database to the latest schema |

## Chat commands

Type a slash in the message box to see them.

| Command | What it does |
|---|---|
| `/modelo` | Changes the model. Without a name it opens the model menu: `/modelo opus` |
| `/agente` | Sends the next messages to an agent: `/agente vera` |
| `/proyecto` | Changes the active project: `/proyecto principal` |

## Keyboard shortcuts

On macOS use Cmd instead of Ctrl.

| Shortcut | What it does |
|---|---|
| Ctrl N | New conversation |
| Ctrl K | Search conversations |
| Ctrl and backtick | Open or close the terminal |
| Ctrl B | Left menu: expanded, icons or hidden |
| Ctrl J | Right panel |
| Ctrl Shift F | Full screen |
| Ctrl comma | Settings |
| Esc | Closes a menu or a window |
