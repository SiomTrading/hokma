# Citations

Every claim in an analysis report carries a numbered citation. The numbers point to a source list that you build while
you retrieve each source, not afterwards from memory.

## How to build the list

1. When a tool call or a file gives you a fact, add one line to the source list at that moment: number, what it is, where
   it came from (tool name and arguments, or file path), and the cut-off time of the data.
2. Write the claim in the report with its number in square brackets, for example: "Revenue grew 12% year over year [3]."
3. Reuse the same number when the same source supports another claim. Never renumber after the report is written.
4. A calculation is a source too: cite the registry function and its inputs, and show the formula in words.

## What is not verified

- A statement you could not tie to a retrieved source is marked **unverified** in the sentence itself. It does not get a
  number and it never supports a conclusion on its own.
- A source that failed to load, returned no data or returned stale data is listed as such. The claim that depended on it
  is dropped or marked unverified.
- Never cite a source you did not retrieve in this run. Never invent a link, a page, a date or a quote.

## Quotes

Quote only text you can copy exactly. If you only remember the idea, paraphrase it without quotation marks and cite it.
